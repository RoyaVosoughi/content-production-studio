# استودیوی تولید محتوا

یک استودیوی تولید محتوا برای برند شخصی که روی کامپیوتر خودتان اجرا می‌شود. ایده‌های به‌روز را از خبرهای همین هفته پیدا می‌کند، آن‌ها را با لحن خود شما می‌نویسد و هر ایده‌ی تأییدشده را برای هر شبکه به یک پست جداگانه تبدیل می‌کند: یادداشت تلگرام، پست لینکدین، کاروسل اینستاگرام، مقاله‌ی وبلاگ، و فیلم‌نامه‌ی ویدیوهایی که خودتان فیلم می‌گیرید و استودیو تدوینشان می‌کند.

هیچ چیزی بدون کلیک شما منتشر نمی‌شود، و هر تأیید دقیقاً به همان نسخه‌ای وصل است که دیده‌اید.

- **برند شما، لحن شما.** در صفحه‌ی **تنظیمات** نام، زبان‌ها، حساب‌ها، وب‌سایت و رنگ‌هایتان را وارد می‌کنید. برای هر زبان یک **کیت برند** دارید (جایگاه، مخاطب، محورهای محتوایی، راهنمای لحن و نمونه‌نوشته‌ها) که پایه‌ی همه‌ی نوشته‌هاست.
- **یک یا دو زبان.** به یکی از ۱۵ زبان بنویسید یا به یک جفت زبان. با دو زبان، هر ایده و پست اول به زبان اصلی نوشته می‌شود و بعد برای زبان دوم بازنویسی می‌شود؛ آن‌طور که یک نویسنده‌ی بومی می‌نویسد، نه ترجمه‌ی کلمه‌به‌کلمه.
- **تیم هوش مصنوعی.** نُه نویسنده که هر کدام یک کار دارند، به‌اضافه‌ی یک مدیر که پیش‌نویس‌ها را بررسی می‌کند و یک مربی که از ویرایش‌ها و تصمیم‌های شما درس می‌گیرد. می‌توانید به هر عضو دستورهای خودش را بدهید.
- **انتشار.** تلگرام، لینکدین، اینستاگرام و وب‌سایت شما از طریق API رسمی خودشان؛ یا دستی (کپی، دانلود و ثبت انتشار) هر جا اتصالی تنظیم نشده باشد.
- **ویدیو.** فیلمی را که گرفته‌اید بارگذاری کنید. استودیو با Whisper روی کامپیوتر خودتان متن آن را درمی‌آورد، تدوینی پیشنهاد می‌کند (برش، زیرنویس، کارت عنوان، زوم، فصل‌بندی) و با FFmpeg و با فونت و رنگ‌های برند شما آن را می‌سازد.
- **رایگان برای امتحان.** به‌طور پیش‌فرض از مدل‌های رایگان OpenRouter استفاده می‌کند، و اگر کلید Anthropic اضافه کنید از Claude.

> **امنیت:** ورود با رمز ندارد. استودیو فقط روی `127.0.0.1` در دسترس است، پس فقط کامپیوتر خودتان می‌تواند آن را باز کند. هر کس بتواند آن را باز کند می‌تواند به نام شما پست بگذارد، پس **پیش از اجرا روی هر جای دیگری، احراز هویت اضافه کنید.**

## پیش‌نیازها

- Node.js نسخه‌ی ۲۰ یا بالاتر
- Google Chrome، برای ساختن تصویر اسلایدها و کارت‌های ویدیو
- FFmpeg، فقط برای ویدیو (ویندوز: `winget install Gyan.FFmpeg`، مک: `brew install ffmpeg`، لینوکس: با مدیر بسته‌ها)
- حدود ۲ گیگابایت فضای خالی برای کار با ویدیو. مدل تبدیل گفتار به متن (حدود ۱٫۱ گیگابایت) با اولین فیلم دانلود می‌شود.

## شروع سریع

</div>

```bash
git clone https://github.com/RoyaVosoughi/content-production-studio.git
cd content-production-studio
npm install
cp .env.example .env.local   # then add OPENROUTER_API_KEY and TAVILY_API_KEY
npm run dev
```

<div dir="rtl">

آدرس http://127.0.0.1:3000 را باز کنید. استودیو با صفحه‌ی **تنظیمات** شروع می‌شود:

1. نام شما و یک یا دو زبان محتوا.
2. برای هر زبان: یک خط درباره‌ی کاری که می‌کنید، و نامتان اگر در آن زبان طور دیگری نوشته می‌شود (مثلاً با الفبای دیگر).
3. در صورت تمایل، نام حساب‌ها، وب‌سایت و رنگ‌های اسلایدها و ویدیوها.

بعد **کیت برند** را برای هر زبان پر کنید. ایده‌ها دقیقاً از آن پیروی می‌کنند؛ پس هر چه نمونه‌نوشته‌ی واقعی بیشتری بگذارید، استودیو بیشتر شبیه خود شما می‌نویسد.

کلیدها: [OpenRouter](https://openrouter.ai/keys) (مدل‌های رایگان) یا کلید Anthropic، به‌اضافه‌ی [Tavily](https://app.tavily.com) برای جست‌وجوی خبر. بقیه‌ی تنظیمات اختیاری‌اند و در فایل `.env.example` توضیح داده شده‌اند.

## زبان‌ها

رابط کاربری به انگلیسی یا فارسی است. محتوا را می‌توان به این زبان‌ها نوشت: انگلیسی، فارسی، عربی، اسپانیایی، فرانسوی، آلمانی، ایتالیایی، پرتغالی، هلندی، سوئدی، لهستانی، ترکی، اندونزیایی، روسی و اوکراینی. زبان‌های راست‌به‌چپ، زیرنویس‌ها و اسلایدها بدون تنظیم اضافه کار می‌کنند.

این فهرست به خط‌هایی محدود است که فونت‌های همراه پروژه می‌توانند بنویسند (Inter برای لاتین و سیریلیک، Vazirmatn برای خط عربی و فارسی). برای افزودن زبان، یک مورد به `CONTENT_LANGUAGES` در `src/lib/language.ts` اضافه کنید، با جهت، خط و سه عبارت کوتاهی که استودیو روی اسلایدها و کارت پایانی می‌نویسد.

با دو زبان، کلید **زبان محتوا** در منو ظاهر می‌شود.

## اتصال‌ها

صفحه‌ی **اتصال‌ها** نشان می‌دهد چه چیزهایی تنظیم شده و هر تنظیمِ ناقص برای چیست. این صفحه فقط دسترسی را بررسی می‌کند و هرگز پستی نمی‌گذارد.

| شبکه | چه لازم دارد | بدون آن |
| --- | --- | --- |
| تلگرام | `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHANNEL_ID` (ربات باید ادمین کانال باشد) | در دسترس نیست |
| لینکدین | `LINKEDIN_ACCESS_TOKEN` | متن را کپی کنید، خودتان پست بگذارید و آن را ثبت کنید |
| اینستاگرام | `INSTAGRAM_ACCESS_TOKEN` (حساب Business یا Creator)، به‌اضافه‌ی `SUPABASE_URL` و `SUPABASE_SECRET_KEY` برای لینک عمومی تصاویر | اسلایدها را دانلود کنید، خودتان پست بگذارید و آن را ثبت کنید |
| وب‌سایت | یک وب‌هوک یا یک جدول Supabase (پایین‌تر) | در دسترس نیست |
| ویدیوها | فعلاً همیشه دستی منتشر می‌شوند | ویدیو و تصویر کوچک را دانلود کنید |

### انتشار در وب‌سایت شما

یکی از این دو راه را انتخاب کنید.

**الف. وب‌هوک.** `WEBSITE_WEBHOOK_URL` (و در صورت تمایل `WEBSITE_WEBHOOK_SECRET`) را تنظیم کنید. استودیو یک درخواست `POST` با این بدنه‌ی JSON می‌فرستد:

</div>

```json
{
  "event": "article.publish",
  "id": "piece-id-v3",
  "language": "en",
  "slug": "why-small-bakeries-should-automate-orders",
  "title": "…",
  "excerpt": "…",
  "body_markdown": "…",
  "tags": ["automation"],
  "url": "https://example.com/en/blog/why-small-bakeries-should-automate-orders",
  "published_at": "2026-11-10T09:00:00.000Z"
}
```

<div dir="rtl">

هدرها: `Content-Type: application/json`، `Idempotency-Key: <id>` (در تلاش دوباره همان مقدار است، تا مقاله دو بار منتشر نشود)، و اگر رمز تنظیم شده باشد `Authorization: Bearer <WEBSITE_WEBHOOK_SECRET>`.

با هر وضعیت `2xx` پاسخ دهید. می‌توانید `{ "id": "…", "url": "…" }` برگردانید تا استودیو بداند مقاله کجا منتشر شد. اگر slug تکراری است `409` و اگر رمز اشتباه است `401` یا `403` برگردانید. هر `5xx` یا قطع اتصال به معنای «شاید منتشر شده» است و استودیو پیش از ارسال دوباره از شما می‌خواهد بررسی کنید. این روش با n8n، Zapier، Make، وردپرس، Ghost یا سایت خودتان کار می‌کند.

**ب. Supabase.** `SUPABASE_URL` و `SUPABASE_SECRET_KEY` را تنظیم کنید. هر مقاله برای هر زبان یک ردیف در جدول `blog_posts` می‌شود (یا جدولی که در `WEBSITE_SUPABASE_TABLE` نام برده‌اید):

</div>

```sql
create table blog_posts (
  id uuid primary key default gen_random_uuid(),
  locale text not null,
  slug text not null,
  title text not null,
  excerpt text not null default '',
  body_md text not null,
  tags text[] not null default '{}',
  status text not null default 'draft',
  published_at timestamptz,
  updated_at timestamptz not null default now(),
  unique (locale, slug)
);
```

<div dir="rtl">

در هر دو حالت، آدرس مقاله از وب‌سایت شما و الگوی «جای هر مقاله» در صفحه‌ی **تنظیمات** ساخته می‌شود، مثلاً `/{lang}/blog/{slug}`.

## تیم هوش مصنوعی

هر عضو یک کار و درس‌های خودش را دارد (صفحه‌ی **ایجنت‌ها**): ایده‌یاب، سناریونویس، نویسنده‌ی زبان دوم (فقط با دو زبان)، نویسنده‌ی تلگرام، نویسنده‌ی لینکدین، طراح کاروسل، نویسنده‌ی وبلاگ، فیلم‌نامه‌نویس ویدیو و تدوینگر ویدیو.

- **دستورها:** هر عضو صفحه‌ی خودش را برای دستورهای ثابت شما دارد: یک کادر برای همه‌ی کارها، و با دو زبان یک کادر برای هر زبان. فقط همان عضو آن‌ها را می‌خواند.
- **مدیر:** به هر پیش‌نویس از ۱ تا ۱۰ نمره می‌دهد و هر چیزی زیر ۷ را یک بار با دلیل برمی‌گرداند. برای صرفه‌جویی در درخواست‌های هوش مصنوعی می‌توان آن را متوقف کرد.
- **مربی یادگیری:** بعد از ۶ بازخورد تازه (ویرایش‌ها، درخواست تغییرها، ردها و تأییدهای شما، و یافته‌های مدیر)، یا وقتی روی «همین حالا یاد بگیر» کلیک کنید، درس‌های آن عضو را بازنویسی می‌کند. درس‌هایی که خودتان اضافه کرده‌اید هرگز تغییر نمی‌کنند.
- **تحلیل:** چند روز بعد از انتشار هر پست، آمار آن را در صفحه‌ی **تحلیل** وارد کنید. هر پست فقط با پست‌های دیگر شما در همان شبکه مقایسه می‌شود، و ایده‌یاب و نویسنده‌ها از آنچه جواب داده یاد می‌گیرند.
- **نمونه‌های تدوینگر:** ویدیوهایی را که تدوینشان را دوست دارید بارگذاری کنید. استودیو ریتم آن‌ها را روی کامپیوتر شما اندازه می‌گیرد و تدوینگر هنگام برنامه‌ریزی تدوین از این اعداد و یادداشت‌های شما استفاده می‌کند.

## داده‌های شما

همه چیز در پوشه‌ی `.data/` روی کامپیوتر شما می‌ماند: پایگاه داده، فیلم‌ها، ویدیوهای نهایی و مدل گفتار. سرویس هوش مصنوعی فقط متنی را می‌بیند که باید بنویسد یا بررسی کند. تصاویر اسلایدها فقط وقتی در اینستاگرام پست می‌گذارید به فضای ذخیره‌سازی Supabase شما می‌روند.

برای استفاده از یک Postgres آنلاین به‌جای پایگاه داده‌ی محلی، `DATABASE_URL` را تنظیم کنید. در حالت production (`npm run build && npm start`)، تنظیم `DATABASE_URL` الزامی است.

جای هر چیز:

- `src/lib/profile.ts`: استودیو برای چه کسی کار می‌کند (تنظیمات)
- `src/lib/language.ts`: زبان‌های رابط کاربری و محتوا
- `src/lib/studio.ts`: ایده‌ها، سناریوها، تأیید و نسخه‌ها
- `src/lib/content.ts`: پست‌های هر شبکه، و قواعد تأیید و انتشار که جلوی انتشار تکراری را می‌گیرند
- `src/lib/ai/writer.ts`: همه‌ی پرامپت‌ها. `{OWNER}` با نام شما جایگزین می‌شود
- `src/lib/agents/`: فهرست تیم، بررسی‌های مدیر، بازخوردها، درس‌ها و مربی
- `src/lib/publishers/`: یک اتصال برای هر شبکه
- `src/lib/slides.ts`، `src/lib/video/overlays.ts`، `src/lib/brand-style.ts`: قالب‌های اسلاید، کارت ویدیو و تصویر کوچک
- `src/lib/video/`: تبدیل گفتار به متن، برنامه‌ی تدوین و ساخت ویدیو
- `src/lib/i18n.ts`: متن‌های رابط کاربری به انگلیسی و فارسی
